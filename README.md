# Embedded Simulator – Virtual ECU

A C++20-based software project focused on developing a simulated Electronic Control Unit (ECU) for motor control.

## Version 0.05 – Initial Project Setup

This version establishes the foundational development environment:

* C++20 and G++ compiler configuration.

* CMake-based build system.

* Debug configuration with compiler warnings and sanitizers.

* GDB debugging support.

* Bash build management script.

* Initial Git repository structure and documentation.

The application currently contains a basic Hello World implementation to verify the build and execution workflow.

**Development is ongoing.** The next milestone is implementing the initial ECU state machine and command interface.
